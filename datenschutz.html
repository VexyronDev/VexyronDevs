Datenschutz

Wer ist verantwortlich?

VexyronDevs (privates Testprojekt), E-Mail: vexyrondevs@gmail.com

Was wird gespeichert?

  • Konto: dein Name und ein Passwort-Hash (das Passwort selbst wird nicht gespeichert), das Datum der Anmeldung und ein Zähler, wie viele Nachrichten du heute geschrieben hast.
  • Chats, Einstellungen, Gedächtnis und erstellte Bilder: Sie liegen auf deinem Gerät und zusätzlich verschlüsselt auf dem Server, damit du sie auf allen Geräten hast. Die Verschlüsselung passiert auf deinem Gerät, dein Passwort ist der Schlüssel. Der Server und der Betreiber sehen nur unlesbare Daten und können sie nicht öffnen. Wenn du dein Passwort vergisst, lassen sich die Daten nicht wiederherstellen. Löschst du dein Konto, werden sie auf dem Server gelöscht.
  • Community-Galerie: Nur wenn du ein Bild selbst mit „In Community teilen“ veröffentlichst, wird es mit deinem Namen auf dem Server gespeichert. Der Betreiber gibt es erst frei; danach können es andere Nutzer sehen und speichern. Du kannst es jederzeit wieder entfernen, es wird auch beim Löschen deines Kontos entfernt.
  • Nachrichten: Wenn du etwas schreibst, läuft der Text zur Verarbeitung durch den Server zur KI und zurück. Er wird dabei nicht gespeichert und nicht protokolliert.
  • Internetsuche: Wenn Vexyron etwas nachschlägt, wird nur der Suchtext an Suchmaschinen (DuckDuckGo, Bing) geschickt, nicht dein Chat und nicht dein Name.
  • IP-Adresse: Sie wird kurz im Arbeitsspeicher gehalten, um zu viele Anmeldeversuche zu bremsen, und nicht dauerhaft gespeichert.

Wer bekommt Daten?

  • Cloudflare leitet die Verbindung zwischen deinem Gerät und dem Server weiter (Tunnel). Dabei verarbeitet Cloudflare technisch bedingt Verbindungsdaten.
  • GitHub Pages liefert diese Webseite aus. GitHub kann dabei die IP-Adresse der Besucher verarbeiten.

Deine Rechte

Du kannst jederzeit Auskunft verlangen und dein Konto löschen. Das geht in der App unter Einstellungen › Konto › „Konto löschen“. Dann sind Name und Passwort-Hash vom Server entfernt, und die Daten auf deinem Gerät werden gelöscht.

Hinweis zum Betrieb

Der Server läuft auf einem privaten Rechner und ist nicht immer erreichbar. Gib keine Passwörter oder sehr persönliche Dinge in den Chat ein.
